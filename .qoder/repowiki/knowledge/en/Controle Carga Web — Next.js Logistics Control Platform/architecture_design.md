The root wires together ten child modules into a single Next.js app: `pages_and_routes` expose serverless API endpoints and page routes; `components` render the React UI built on MUI + Tailwind; `services` call external logistics providers (SSW portal/tracking, ERP) and internal Next.js APIs; `lib` centralizes server-side concerns (Prisma client, auth, caching, ZPL generation); `prisma_schema` defines the PostgreSQL model consumed by both `lib` and `scripts_and_migrations`; `shared_types` provides the TypeScript contracts and Zustand store used by both UI (`contexts_hooks`, `components`) and API handlers; `utils_and_styles` supplies cross-cutting helpers, theme, and print utilities; `tests` exercise label generation, dashboard rules, and sync logic against mocked services. The `middleware.ts` enforces CORS and cookie handling for all `/api/*` routes, while `next.config.js` configures SWC minification, ignores TS/ESLint build errors, and marks `@prisma/client` as an external server package. Deployment is driven by `package.json` scripts (`build` runs `prisma generate && next build`, `postinstall` regenerates Prisma), with environment-specific configs in `vercel.json`, `netlify.toml`, and `windsurf_deployment.yaml`.
