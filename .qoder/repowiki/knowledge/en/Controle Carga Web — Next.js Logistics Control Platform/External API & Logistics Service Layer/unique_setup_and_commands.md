Requires environment variables per integration: `NEXT_PUBLIC_API_URL` (internal API base), `API_EXTERNA_BASE_URL` / `API_EXTERNA_USERNAME` / `API_EXTERNA_PASSWORD` (external ERP), `SSW_ACCERT_*`, `SSW_EXPRESSO_GOIAS_*`, `SSW_ZANUELLO_*` (SSW portal accounts), `NEXT_PUBLIC_OPENCAGE_API_KEY` (geocoding), and `NEXT_PUBLIC_QZ_TRAY_CERT` / `NEXT_PUBLIC_QZ_TRAY_SIGNATURE_ENDPOINT` (QZ Tray certificate and signature endpoint). The SSW portal login flow depends on specific hidden form fields (`backimg`, `seq_ctrc`) extracted from rendered HTML.
