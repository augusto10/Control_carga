Scripts require a Postgres connection URL set as `DATABASE_URL` or `DIRECT_URL` in the environment. Production Prisma client generation is done through `scripts/prisma/generate.js` which sets `PRISMA_GENERATE_DATAPROXY=false` and runs `npx prisma generate --no-engine`. Many production fixes are invoked directly, e.g. `npx ts-node scripts/sync-production-db.ts`, `npx ts-node scripts/apply-migration.ts`, or `node scripts/executar-migracao-producao.js`.
