Flat directory of independent functional React components under `components/`, each exporting a default component consumed by feature pages. Components are grouped by concern: barcode/note entry (`AdicionarNotasContent`, `CriarControleContent`, `ListarControlesContent`), signature workflow (`SignaturePadPro` with undo/redo history via `signature_pad`, wrapped in `ModalAssinaturaDigitalPro` and `ModalAssinaturaSimplesAlternativo` plus `AssinaturaSimples`), media capture (`ImageCapture` using `getUserMedia` + canvas, `AndroidCamera`, `AndroidScanner`), mapping (`LeafletMap` wrapping `react-leaflet` with custom div icons, route polylines via `RoutingService`, and a thin `Map` wrapper), form helpers (`InputMask` bridging `react-input-mask` to MUI `TextField` or local `ui/Input`), layout utilities (`ResponsiveContainer`, `ResponsiveTable` switching between table and card layouts via `useMediaQuery`, `GlobalBackground`), and session UI (`UserMenu` reading auth from `../contexts/AuthContext`). Cross-component dependencies flow outward only — components import from `@mui/*`, `react-leaflet`, `signature_pad`, `notistack`, `next/router`, and sibling services like `../services/routing` or `../store/store`; they do not depend on each other except `ModalAssinaturaDigitalPro` → `SignaturePadPro`. No shared index barrel; consumers import files directly.
