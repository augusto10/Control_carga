Components are grouped by domain: `ui/` holds generic presentational primitives (Button, Card, Modal, Input, Select, Badge, StatCard) consumed everywhere; `layout/`, `admin/`, and `dashboard/` compose those primitives into page-level shells for app-wide navigation, admin routing, and order-status dashboards; `labels/` provides label printing and preview widgets; top-level files expose cross-cutting capabilities such as Android camera/scanner bridges, digital signature pads, Leaflet maps, responsive containers/tables, and route guards. Feature directories import from `ui/` and from each other only through explicit file paths — there is no central barrel or index, so consumers resolve components by their relative path under `components/`.
