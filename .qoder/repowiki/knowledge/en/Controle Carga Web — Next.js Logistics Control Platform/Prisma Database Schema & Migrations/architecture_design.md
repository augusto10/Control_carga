The module centers on a single Prisma schema (`schema.prisma`) that declares all domain models (ControleCarga, Pedido, NotaFiscal, Usuario, EtiquetaLote, ChecklistRecebimento, Roteirizacao, etc.) with explicit relations, indexes, and enums such as Transportadora, TipoUsuario, StatusValidacao. The datasource targets PostgreSQL with `DATABASE_URL` from environment variables, and the generator produces `prisma-client-js` with native and debian-openssl-3.0.x binary targets. A shared singleton PrismaClient is exposed via `config.ts` (TypeScript) and `client.js` (CommonJS), both caching the instance in `globalThis` outside production to avoid connection leaks. Versioned database migrations live under `migrations/` as timestamp-prefixed folders each containing a `migration.sql`, plus legacy flat `.sql` files; `migrations/migration_lock.toml` pins the provider to PostgreSQL. Seed logic (`seed.ts`) bootstraps default users using bcrypt-hashed passwords, and a collection of standalone `.sql` and `.ts` helpers under `prisma/` provide one-off admin creation, user checks, table introspection, and connection tests used during development and deployment.
