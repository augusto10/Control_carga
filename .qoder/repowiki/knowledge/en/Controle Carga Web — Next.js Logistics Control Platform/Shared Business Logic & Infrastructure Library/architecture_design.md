The `lib/` directory is a flat collection of reusable server modules consumed by Next.js API routes and background jobs. It is organized into four conceptual layers:

- **Infrastructure singletons**: `prisma.ts` (process-scoped PrismaClient with development-time global leak), `supabase.ts` (Supabase client from env), and `api.ts` (Axios instance targeting the local backend).
- **Auth layer**: `auth.ts` extracts JWTs from cookies via `nookies` and verifies them; `server-auth.ts` resolves a full user row from Prisma after verifying a cookie or Bearer token; `middleware/withAuth.ts` wraps handlers to attach a typed `user` onto `NextApiRequest`.
- **Domain services** (one per business area): `logistica-snapshot.ts` orchestrates syncing orders from an external ERP (`@/services/api-externa`) into `pedidoLogisticaSnapshot`/`sincronizacaoLogistica`, deriving operational status, alerts, and pending items; `dashboard-external-cache.ts` provides in-process TTL + deduplicated request caching for dashboard calls; `erp-separacao-automation.ts` spawns a Python script (`scripts/erp_emitir_lista_separacao.py`) with timeout and JSON stdout parsing; `barcode-validation.ts` validates EAN-8/EAN-13 checksums and detects CODE128.
- **Label & transport persistence**: `zpl-generator.ts` / `zpl-transport.ts` build Zebra ZPL output from product data using `barcode-validation`; `etiquetas-repo.ts` / `etiquetas-transporte.ts` perform raw SQL against `EtiquetaLote`/`EtiquetaVolume` with dynamic column selection so missing `cnpj` columns do not break production deployments; `freteDf.ts`, `gerarNumeroManifesto.ts`, `label-products-catalog.ts`, `product-label.ts`, `pedido-apresentacao.ts`, `pedido-embarques-atuais.ts`, `pedido-logistica-atual.ts`, `pedido-pendencias.ts`, `perfil6m.ts`, `dashboard-freshness.ts`, `deviceUtils.ts`, `imageUtils.ts` each encapsulate one domain concern.

Dependency direction is strictly inward: this module depends on `@/types/*`, `@/services/api-externa`, and `@/lib/prisma`, but is never imported by those services. Cross-cutting concerns (auth, cache, Prisma) are reused by every domain file rather than being passed as parameters.
